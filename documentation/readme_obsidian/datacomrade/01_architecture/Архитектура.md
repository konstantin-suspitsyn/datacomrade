# Архитектура

Точка входа в описание архитектуры datacomrade — self-service BI: пользователь собирает запрос мышкой, система детерминированно генерирует SQL (без ИИ), выполняет его и возвращает данные.

![[arch.png]]

Редактируемая версия схемы: `architecture_diagram.excalidraw` (Excalidraw plugin или excalidraw.com).

## Компоненты

| Сервис | Роль |
| --- | --- |
| [[API Gateway]] | Единая точка входа, валидация JWT, роутинг |
| [[Metadata Service]] | Каталог данных и права доступа (реализован как `datacatalogue`) |
| [[Query Builder Service]] | Сборка SQL под диалект целевой СУБД |
| [[Query Execution Service]] | Выполнение SQL, лимиты, пулы соединений |

## Что важно не сломать

Query Builder физически не имеет доступа к целевым базам: он не хранит и не получает учётные данные подключений. Единственная точка, где приложение реально соединяется с базами — [[Query Execution Service]]. Это граница безопасности, а не деталь реализации: если Builder «для удобства» получит коннект к БД, вся модель проверки прав перед генерацией SQL теряет смысл.
