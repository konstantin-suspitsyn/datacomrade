# Query Execution Service

Единственный сервис с реальными подключениями к целевым базам. На вход получает готовый SQL + параметры + идентификатор базы от [[Query Builder Service]].

## Гарантии

- Таймаут выполнения (statement timeout) и лимит числа возвращаемых строк.
- Сессия только на чтение. Для ClickHouse это `readonly=1`, `max_execution_time`, `max_result_rows`, `max_memory_usage`; для остальных — read-only роль/транзакция.
- Отдельный пул соединений на каждую целевую базу: тяжёлый отчёт по одному источнику не должен выедать коннекты к другому.
- Публикация события аудита (кто, какой запрос, когда, сколько строк) в брокер сообщений.

## Учётные данные

Берутся из окружения по именам переменных, записанным в [[dc.host]] (`host_env`, `port_env`, `username_env`, `password_env`). Права пользователя БД, под которым ходит сервис, должны быть минимальными — только SELECT на нужные схемы. Это последний рубеж: даже при ошибке в генерации SQL запись в источник должна быть невозможна на уровне прав СУБД.

## Масштабирование

Сервис масштабируется горизонтально, но его нельзя разгонять независимо от целевых баз: каждый новый под добавляет пул соединений к источнику. Число реплик × размер пула должно укладываться в лимит соединений целевой базы — см. [[Развертывание]].
