# Перезапуск микросервисов - рабочий процесс
Что нужно сделать, если ты забыл как запускать все
1. Необходимо сгенерить env файлы ```task env:generate``` [[Работа с env файлами]]
2. Поднять все контейнеры ```task up-all``` [[Taskdetail]]
3. Если есть бд. Запускаем goose. Сейчас это делается в каждом микросервисе. Я это переделаю. Все настройки в env файле [[Goose]]
4. Запускаем sqlc [[sqlc_generation]]
5. Включаем в каждом микросервисе sqlc
